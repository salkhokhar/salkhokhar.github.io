# salkhokhar.github.io

Personal resume site for Sahil Khokhar, served by GitHub Pages at <https://salkhokhar.github.io>.

Plain static HTML and CSS, no build step.

- `index.html` — the page content (experience, skills, projects, publications, education)
- `styles.css` — dark theme, single accent colour
- `asset/resume.pdf` — the downloadable resume
- `asset/headshot.png` — hero photo

To update: edit `index.html`, replace `asset/resume.pdf`, push to `main`.
